# Контентная модель для рабочего сайта

Демо использует локальный JSON, но его блоки спроектированы как будущие коллекции Directus.

| Коллекция | Основные поля | Назначение |
| --- | --- | --- |
| `site_settings` | телефон, адрес, соцсети, SEO по умолчанию | Общие данные сайта |
| `navigation_items` | подпись, тип цели, путь, позиция, видимость | Редактируемое верхнее и нижнее меню; ссылки на новые страницы |
| `home_banners` | заголовок, текст, изображение, CTA, позиция, даты активности | Сменяемые hero-баннеры каждого направления |
| `home_category_tiles` | категория Medusa, заголовок, изображение, позиция, видимость | Сетка категорий под hero, по принципу PRISM |
| `content_pages` | slug, title, SEO, статус, язык, блоки | Страницы, созданные администратором |
| `page_blocks` | тип, позиция, заголовок, текст, медиа, видео | Редактируемые секции информационных страниц |
| `media` | файл, alt, автор/правообладатель | Безопасная замена изображений |

Товары, варианты, категории, цены, остатки, промокоды, корзина, заказы и платежи принадлежат Medusa. Directus хранит только ссылки на идентификаторы категорий и товаров Medusa, а также редакторские блоки. Такая граница устраняет два источника истины для цен и остатков.

На публичном сайте Nuxt получает опубликованный контент Directus и каталог Medusa через серверный слой, где можно контролировать кеш и скрыть административные ключи. При смене баннера или порядка плиток кэш главной сбрасывается вебхуком. При добавлении страницы администратор публикует её в Directus и добавляет пункт в `navigation_items`; маршрут `/pages/[slug]` строится без правки кода.

Для варианта без Directus пришлось бы разработать и поддерживать собственные модели блоков, редактор, загрузку медиа, статусы публикации и управление меню внутри Medusa. При небольшом ассортименте это не даёт преимущества: объём товарного каталога мал, а требования к редактированию контента заметны.

Перед рабочим запуском отдельно проверяются юридические тексты, фактические контакты, платёжный провайдер, российские требования к персональным данным и права на изображения. Демо не заменяет эти решения.
