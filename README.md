# APEKS GNSS — дизайнерские версии

Статическая публикация сайта из архива дизайнера `apeks-gnss-variants.zip`.

- `/` — вариант с тёмной шапкой (`site/index.html`).
- `/variant-2/` — корпоративный вариант с белой шапкой (`site/variant-2/index.html`).

GitHub Pages публикует содержимое `site/` после обновления ветки `main`. Старое Nuxt-демо осталось только в истории и исходниках репозитория; в опубликованный артефакт оно не входит.

Обе версии автономны на уровне HTML и локальных изображений, но подключают шрифты Google и Tailwind CDN. Каталог, корзина и форма остаются демонстрационными. Форма не отправляет заявку и сообщает об этом при нажатии. Для рабочего магазина потребуются серверная часть и подтверждение контента, цен и контактов.

Исходный ZIP дизайнера хранится вне репозитория. Предыдущий архив сайта исполнителя также не входит в публикацию.
