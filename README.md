# APEKS · три направления интернет-магазина

Демонстрационный проект на Nuxt 4 / Vue 3. На входе — экран выбора из трёх направлений: «Бренд и категории», «Быстрый выбор» и «Продуктовая витрина». Первое ведёт от полевого изображения к категориям, второе сразу показывает ассортимент и цены, третье использует продуктовую графику производителя. Каталог, карточки товаров и информационные страницы используют общие данные.

## Локальный запуск

```bash
npm ci
npm run dev
```

`npm run typecheck` проверяет типы. `npm run generate` создаёт статическую версию в `.output/public`. Сборка содержит 147 страниц исходной карты сайта в каждом из трёх направлений и экран выбора — 442 HTML-страницы. Англоязычные маршруты и некоторые служебные страницы в демо используют упрощённый шаблон; полноценная локализация и серверная логика относятся к рабочему этапу.

## Состав демо

- `/` — выбор направления;
- `/v1`, `/v2`, `/v3` — главные страницы;
- `/<вариант>/products`, `/<вариант>/category/<slug>`, `/<вариант>/products/<slug>` — каталог, группы и карточки;
- `/<вариант>/<slug>` — информационные страницы, услуги, контакты и правовые разделы.

Корзина, личный кабинет, оплата и отправка заявок пока не подключены. Показанные во втором варианте цены — статичный снимок публичного российского сайта APEKS на октябрь 2026 года. Контактный телефон и названия товаров также взяты из публичных материалов проекта. Перед запуском рабочей версии нужно подтвердить их актуальность у заказчика. Правовые страницы в демо не являются готовыми юридическими документами.

Данные размещены в `app/data/content.json`; фотографии оборудования — в `public/media`. В `public/brand` лежат изображения из публичных сайтов [APEKS GNSS](https://www.apeksgnss.com/) и [APEKS Россия](https://apeksgnss.ru/), использованные для прототипа. Публичный архив сайта прежнего исполнителя **не включён** в репозиторий и хранится отдельно как локальный файл для проектного анализа.

## Рабочий стек после выбора направления

Рекомендуем **Vue 3 / Nuxt + Medusa + Directus**. Medusa отвечает за товарные данные, цены, остатки, корзину, заказы и платежи. Directus — за редактируемые баннеры, категории на главной, составные информационные страницы и меню. Для задачи с гибким контентом это проще и прозрачнее, чем переносить весь редакторский контур в собственный плагин Medusa. Общие сущности связываются стабильными идентификаторами категории и товара. Подробности — в [`docs/content-model.md`](docs/content-model.md).

GitHub Pages публикует демо после обновления ветки `main` по адресу `https://nowa-nn.github.io/apeks/`.
